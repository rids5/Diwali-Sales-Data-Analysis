# 🪔 Diwali Sales Data Analysis

An exploratory data analysis (EDA) project on Diwali sales data in India using Python.

## 📊 What This Project Covers
- Gender-wise buyer and revenue analysis
- Age group trends
- Top 10 states by orders and revenue
- Marital status impact on spending
- Occupation-wise analysis
- Product category performance
- Top 15 products by orders
- Zone-wise revenue + heatmap

## 🛠 Tech Stack
- Python
- Pandas
- NumPy
- Matplotlib
- Seaborn
